# コードひろば

HTML / CSS / JavaScript のコードだけを投稿できる、「企画」単位の投稿サイトです。
フロントエンドは GitHub Pages、ログインとデータ保存は Supabase（無料枠あり）で動きます。

## 機能

- **登録**：メールアドレス・ユーザー名（新規作成）・パスワード
- **ログイン**：ユーザー名とパスワード
- **パスワード再設定**：登録メールアドレスに再設定リンクを送信
- **企画**：企画主が作成。「他の人も投稿OK」か「企画主のみ」かを後から切り替え可能
- **投稿**：「コード入力」または「ファイル添付」（.html / .css / .js）から選べます。HTMLだけ、またはCSS・JavaScriptをHTMLの中に直接書いた形でもOK（通常は各500KBまで。管理者の承認で最大2MBまで）。プレビュー付き
- **メモ**：投稿ページに、投稿者が改善した点などを書けます（投稿の編集画面で入力）
- **コメント**：企画ページに、ログイン済みの人なら誰でも改善点などを書き込めます（削除は本人か企画主）
- **返信・通知**：コメントに返信できます。自分の企画へのコメントや、自分のコメントへの返信があると、サイト左上のベルに通知が出ます
- **大容量投稿**：通常は500KBまで。超える場合は管理者に「要請」でき、管理者が通知（ベル）から、認める回数を決めて承認すると、その回数だけ最大2MBを投稿できます。管理者自身は、常に最大2MBまで
- **まとめて削除**：企画ページの「🗑 まとめて削除」で、投稿を複数選んで一括削除できます（企画主・管理者はすべての投稿、それ以外の人は自分の投稿だけ）
- **一般公開 / 限定公開**：投稿ごとに「このhtmlを一般公開する」を設定（初期値は公開、投稿後も変更可）。限定公開は企画の一覧には出ますが、プレビュー・コード閲覧・ダウンロードは、作成者・企画主・共同編集者・管理者と、作成者がユーザー名で追加した人だけ。それ以外の人には「公開を要請」ボタンが出て、押すと作成者に通知されます
- **共同編集者**：企画主が、ユーザー名で検索して追加・削除できます。企画の設定変更と、企画への投稿ができます
- **ユーザー管理（管理者のみ）**：登録ユーザーのユーザー名・メールアドレス・認証状況の一覧と、アカウント削除
- **通知**：自分で削除でき、1週間で自動的に削除されます
- **管理者**：管理者アカウントは、すべての企画・投稿・コメントを編集・削除できます（管理者の指定は SQL Editor から。パスワードなどはコードに書きません）。限定公開の投稿もすべて見られ、どの企画にも投稿できます
- **ダウンロード**：未ログインでも誰でも可能（投稿単位：1ファイルHTML / ZIP、企画単位：まるごとZIP）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | サイト本体 |
| `config.js` | Supabase の接続情報（あなたの値に書き換える） |
| `schema.sql` | データベースの設定（Supabase で1回だけ実行） |
| `migration_limit_500kb.sql` | 【上限を500KBに上げる前に schema.sql を実行済みの方だけ】更新用 |
| `migration_admin.sql` | 【管理者機能の追加】すでに schema.sql を実行済みの方向け（管理者アカウントの登録も含む） |
| `migration_reply_notify.sql` | 【返信・通知（ベル）の追加】すでに schema.sql を実行済みの方向け |
| `migration_big_upload.sql` | 【大容量投稿（要請・承認制）の追加】すでに schema.sql を実行済みの方向け |
| `migration_visibility_collab_admin.sql` | 【一般公開/限定公開・共同編集者・ユーザー管理・通知の自動削除】すでに schema.sql を実行済みの方向け |
| `migration_memo_comments.sql` | 【メモ・コメント追加前に schema.sql を実行済みの方だけ】追加分の更新用 |

## セットアップ手順

### 1. Supabase プロジェクトを作る
1. https://supabase.com でアカウント作成 → **New project**
2. 作成後、**SQL Editor** を開き、`schema.sql` の中身をすべて貼り付けて **Run**

### 2. config.js を書き換える
**Project Settings → API** にある次の2つを `config.js` に貼り付けます。
- Project URL → `SUPABASE_URL`
- `anon` `public` キー → `SUPABASE_ANON_KEY`

> `service_role` キーは絶対に書かないでください。anon キーは公開されても大丈夫な設計です（データは RLS で保護）。

### 3. GitHub Pages で公開する
1. GitHub で新しいリポジトリを作り、このフォルダのファイルをすべてアップロード（push）
2. リポジトリの **Settings → Pages** → Source を **Deploy from a branch**、Branch を `main` / `(root)` にして Save
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

### 4. Supabase に公開URLを教える（重要）
**Authentication → URL Configuration** で次を設定します。
- **Site URL**：`https://<ユーザー名>.github.io/<リポジトリ名>/`
- **Redirect URLs** にも同じURLを追加

これをしないと、確認メール・パスワード再設定メールのリンクが正しく戻ってきません。

### 5. メール送信について
- 初期状態の Supabase のメール送信は**回数制限が厳しい**（1時間に数通程度）ため、実運用では **Authentication → SMTP Settings** で自前のSMTP（Resend、SendGrid など）を設定してください。
- 確認メールを不要にしたい場合は **Authentication → Providers → Email** の「Confirm email」をオフにできます（ただしメールアドレスの正しさは確認されなくなります）。
- パスワード再設定のリンクは、**メールを請求したのと同じブラウザ**で開く必要があります。

## セキュリティ設計と注意点

- **投稿コードの実行は隔離**：プレビューは `sandbox="allow-scripts allow-forms allow-modals"` の iframe（`allow-same-origin` なし）で実行されるため、投稿されたJSからサイトのログイン情報や他ユーザーの操作にアクセスできません。投稿コードをこのサイトのページとして直接ホストすることもしていません。
- **権限はデータベース側（RLS）で強制**：閲覧・ダウンロードは誰でも可。投稿は「企画主、または許可された企画のログイン済みユーザー」だけ。編集は投稿者本人、削除は投稿者本人か企画主だけです。ブラウザ側の画面制御を迂回されても守られます。
- **メールアドレスは公開されません**：ユーザー一覧にはユーザー名だけが入り、メールは Supabase 認証側にのみ保存されます。
- **既知のトレードオフ**：「ユーザー名でログイン」を実現するため、ユーザー名からメールアドレスを引く関数（`email_for_username`）を未ログインでも呼べる設計にしています。そのため、**既知のユーザー名を総当たりすればそのユーザーのメールアドレスを取得できてしまう**弱点があります。公開規模が大きくなる場合は、この関数を Supabase Edge Function に置き換え、ログイン処理をサーバー側で完結させる構成に変更してください。
- **悪意あるコード**：ダウンロードしたコードを実行するのは利用者自身です。サイトには注意書きを表示していますが、通報・管理機能が必要になったら別途追加してください。
- 「コードのみ」の制限は、入力欄をコード専用にすることで実現しています（画像やファイルのアップロードはできません）。

## Vercel で Supabase を中継する（任意）

学校・職場のネットワークなどで `supabase.co` がブロックされる場合、Vercel を中継役にできます。

1. リポジトリのトップに `vercel.json` を置く（`/supabase/...` へのアクセスを Supabase に転送する設定）
2. `config.js` の `SUPABASE_URL` を、Vercel のときだけ `location.origin + "/supabase"` にする
3. 中継に切り替えると、ブラウザの保存するログイン情報の場所が変わるため、一度ログインし直しが必要
